# Rosalia 的知识库

学习笔记，持续更新中。

**在线阅读 → <https://rosalia3001.github.io/Rosalia-notes/>**

记的是每天学到的、想明白的东西：技术原理、产品判断、读过的书。写不完整也照发——半成品比空着强。

## 怎么写一篇

1. 仓库页点 **Add file → Create new file**
2. 文件名填 `notes/2026-10-21-短标题.md`
3. 第一行写 `# 标题`，正文用普通 Markdown
4. 拉到页面底部 **Commit changes**

提交后站点几分钟内自动出现这篇，不需要改任何代码。

## 命名

```
notes/YYYY-MM-DD-短标题.md
```

日期放前面，按文件名排序就是时间顺序。

## 结构

| 路径 | 作用 |
| --- | --- |
| `index.html`、`assets/` | 阅读站点，原生 HTML / CSS / JS，无构建步骤 |
| `notes/` | 笔记源文件，平铺存放 |
| `notes-index.json` | 自动生成的目录，请勿手改 |
