# 学习笔记

自己每天记点东西的地方。

## 怎么加一篇

打开仓库，点右上角 **Add file → Create new file**：

1. 文件名填 `notes/2026-10-20-今天看了什么.md`
2. 正文第一行写 `# 标题`，然后正常写内容
3. 拉到底 **Commit changes**，就发布完了

写错了不要紧，点开文件右上角的铅笔图标随时改，每次提交都会留下历史。

## 命名

```
notes/YYYY-MM-DD-短标题.md
```

日期放前面，文件夹按文件名排序就是时间顺序，不用额外维护目录页。

## 结构

```text
.
├── README.md   # 就是本文件
└── notes/      # 所有笔记，平铺放这里
```

没有模板、没有脚本、没有需要记住的格式。想写就写。
